# WIREFRAMES MVP - ToNaEscala

Wireframes textuais para orientar a construção das telas do MVP mobile.

## 1. Login / Entrada

```text
┌─────────────────────────┐
│ ToNaEscala              │
│ Organize escalas rápido │
│                         │
│ [Entrar com Google]     │
│ [Entrar com email]      │
│                         │
│ Entrar em evento        │
│ [ Código do evento ]    │
│ [Entrar] [Ler QR Code]  │
└─────────────────────────┘
```

Notas:

- Participante deve enxergar a entrada por código sem procurar em menu.
- Organizador tem login completo.
