# Assets Play Store - Minha Escala

Pasta gerada para envio e preparacao da ficha do Google Play Console. Os arquivos originais da pasta `img/` foram preservados.

## Dimensoes usadas

| Pasta | Uso | Dimensao |
|---|---|---|
| `feature-graphic/` | Grafico de destaque da Play Store | `1024x500` |
| `phone/` | Screenshots de celular | `1080x1920` |
| `tablet-7/` | Screenshots de tablet 7" | `1200x1920` |
| `tablet-10/` | Screenshots de tablet 10" | `1600x2560` |
| `adjusted/` | Imagens existentes ajustadas | Varias |

Todos os PNGs foram exportados em `24bpp RGB`, sem canal alpha.

## Arquivos principais

- `feature-graphic/feature-graphic-1024x500.png`: arte de destaque pronta para upload.
- `adjusted/playstore-icon-512x512.png`: icone ajustado para a ficha.
- `adjusted/banner-cover-1024x500.png`: banner existente recortado para feature graphic.
- `adjusted/banner-original-cover-1024x500.png`: segunda opcao de banner recortado.
- `adjusted/logo-horizontal-white-bg-1200x480.png`: logo horizontal em fundo branco.
- `adjusted/telas-sistema-reference-1080x1920.png`: composicao original de telas ajustada para referencia.
